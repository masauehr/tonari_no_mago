## 2. テーマ・コンセプト（要記入）

**暫定案: デジタル弱者のための「画面ガイド＋やさしい表示」ブラウザ拡張**（作業名: となりの孫）

- 解決したい課題: 高齢者など、オンライン手続きや Web サイトの画面で迷って諦める人が多い。家族や窓口に頼れないと、手続き自体ができない
- 想定ユーザー: ブラウザで行政サイトや通販を使うシニア。遠方の家族が設定する場面も想定
- 一言で言うと: 「困った」を押すと、次に押す場所を1つだけ光らせて教え、難しいページはやさしい表示に直す
- 機能（2本柱）:
  - **画面ガイド（案B）**: 「困った」ボタン → 画面と DOM を Claude に渡す → 次に押す場所を1つだけハイライトして理由を一言で説明する
  - **やさしい表示（案C）**: 開いたページを、大きな文字、やさしい日本語、要点のみの表示に変換する
- Claude をどう活用するか: 画像理解（画面の把握）と日本語のやさしい言い換えを Claude に任せる。拡張機能は Claude Code で開発する
- 方針: 実際の手続きは代行せず、案内だけに徹する。デモは疑似の申請ページとダミーデータを使う
- 未決事項:
  - スマホ画面は拡張機能が使えないため、まず PC のブラウザに絞る
  - API キーを拡張に直接持たせない構成（簡易プロキシ）にする
